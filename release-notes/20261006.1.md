Apps are ready the moment Porthole's install finishes, and opening one feels like opening a Mac
app.

- **Installing Porthole prepares every app.** Each app's image is built during the install, each
  in its own window, so the first launch doesn't build anything. An app opened while its install
  is still preparing it opens once the build is done, in one window.
- **Opening an app shows no setup window** when there's nothing to set up. Its Dock icon shows
  progress until the app's window appears. Real work (starting the Docker VM, downloading,
  building), a question or an error still gets a window.
- **Check for Updates…**, and **Restart to Update** once a newer image for the app is ready.
- **Apps run in your Mac's time zone,** and follow it when it changes.
- **Closing a dialog on the Mac closes it in the app,** so asking for it again brings it back.
- **An app's About menu item can open the app's own About,** for example 1Password's Settings → About.
- **The Docker VM is started or waited for** when it's stopped or still starting, instead of an
  error telling you to start it.
- Each launch's stages are recorded in the system log (`porthole: <app>: …`), so a slow one can be
  timed afterwards.
